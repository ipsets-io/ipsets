ipsets.io

IP ranges curated from vendors such as CDNs, crawlers and clouds, refreshed daily. One schema for every provider, separate files per address family, as JSON or bare CIDRs.

Every path is /v1/{provider}/{set}/{family}.{json,txt}, so URLs can be templated with no per-provider special cases. The .txt files are bare CIDRs, one per line.
